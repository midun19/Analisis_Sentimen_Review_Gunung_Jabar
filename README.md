Repository ini merupakan hasil dummy proyek saya mengenai Analisis Sentimen Review Gunung Jawa Barat

Dataset diambil dari review Google Maps dan di scraping menggunakan website Apify. Jumlah Dataset saat di scraping yaitu 27.886 data, setelah di cleaning jumlah data menjadi 10.000 data.
Model yang digunakan untuk pelabelan sentimen yaitu menggunakan model INDOBert dan menggunakan BERTopic untuk menghasilkan topik yang paling sering muncul dalam review
